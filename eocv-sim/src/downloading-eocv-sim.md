# Downloading EOCV-Sim

**1. Install the Java Runtime Environment (JRE) or Java Development Kit (JDK) if you don't have it:**

EOCV-Sim requires Java 11 or newer. You can grab it from [Oracle's download page](https://www.oracle.com/java/technologies/javase-downloads.html).

**2. [Go to the latest EOCV-Sim release on GitHub.](https://github.com/deltacv/EOCV-Sim/releases/latest)**

**3. Download the jar file named `EOCV-Sim-X.X.X-all.jar`, found at the bottom of the page under the "Assets" section:**

![Example screenshot of the latest release as of 17/09/21](assets/example-release.png)

_(The screenshot above may not match what you see, since the page is updated with each new release. The `EOCV-Sim-all` artifact is available in every release.)_

## Running EOCV-Sim

Once downloaded, you can double-click the jar file to launch it, just like any other executable.

You can also run it from the command line. Navigate to the folder containing the jar file using `cd`, then run:

```
java -jar "EOCV-Sim-X.X.X-all.jar"
```

Replace `X.X.X` with the actual version number, e.g. `3.1.0`.
